# Global Music Chart (GMC)

Global Music Chart is a transparent, automated, data-driven music intelligence platform designed to rank songs, empower artists, and connect fans worldwide.

## Current Version

**v0.1 – Foundation Day**

### Completed

- FastAPI backend
- Interactive API documentation
- Artist registration endpoint
- Country API
- Health endpoint
